# Maintenance handbook

Daily: inspect health monitoring, failed jobs, security alerts, notification failures, storage capacity, and backup completion.

Weekly: review crisis flags, referral queues, unassigned consultations, stale appointments, dependency alerts, audit anomalies, and content awaiting review.

Monthly: patch supported dependencies, verify restore samples, review accounts and permissions, inspect AI quality and safety samples, rotate expiring credentials, and report availability and incidents.

Quarterly: full recovery exercise, access recertification, youth usability/accessibility testing, clinical-content review, capacity test, security tabletop exercise, and SLA review.

Changes require a ticket, risk assessment, peer review, automated tests, staging verification, rollback plan, release record, and owner approval. Never modify production data manually without an approved, logged procedure.
