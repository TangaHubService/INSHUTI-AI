# Third-party components and services

The authoritative package names and versions are in the root, frontend, and backend lockfiles. Major runtime components include Next.js/React, Express, Prisma/PostgreSQL, Socket.IO, OpenAI API, Leaflet/OpenStreetMap tiles, Nodemailer/SMTP, optional Twilio SMS, ExcelJS, and PDFKit.

Before production acceptance, generate a software bill of materials, review every license and provider data-processing term, approve AI and notification data flows, configure geographic/data-retention requirements, and record renewal owners. No production health data may be used to train third-party AI models unless expressly authorized by the data controller and lawful.
